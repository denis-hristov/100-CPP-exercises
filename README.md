# 100 C++ Exercises

## About This Project

The goal of these 100 exercises is to improve my coding skills and become a better programmer.

### Why Am I Doing This?

I'm challenging myself to write code without relying on AI.

I believe that writing code on your own is essential for developing real programming skills.

Using less AI doesn't mean working less efficiently. It means learning how to think, solve problems, and understand code independently.

### My Goal

To become a better programmer who can write, understand, and debug code without depending on AI.

**Every line of code I write myself makes me a better programmer.**
